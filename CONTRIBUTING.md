# Contributing

1. Open an issue describing the contract gap and why it is distinct from live MCP inspection.
2. Add adversarial and expected-path tests with synthetic data.
3. Run `npm run check` on Node.js 20 or newer.
4. Keep runtime dependencies at zero unless a reviewed proposal demonstrates a material need.
5. Do not commit credentials, production captures, personal data, generated reports, or employer code.

Contributions are accepted under the MIT license. Follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) and the pull-request template.
