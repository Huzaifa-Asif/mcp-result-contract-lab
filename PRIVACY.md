# Privacy

The app has no account, backend, analytics, telemetry, cookies, database, or network client. Browser inputs and reports remain in the current tab's memory until cleared or closed. The CLI reads the selected local fixture and writes only to stdout/stderr unless the operator redirects output.

Do not include live credentials, personal data, production payloads, or proprietary content. Use sanitized fixtures and placeholders. Downloaded reports are retained only where the browser saves them; the user controls deletion.
